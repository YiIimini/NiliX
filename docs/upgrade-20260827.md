**核验中发现的真金(官方 MotionContext README 链式续写三原则)→ 已实施**:
1. **气闸(airlock)**:接缝镜开头先保持上一镜收尾构图约1秒再发展新内容,官方实测"measure tighter than an ordinary frame-to-frame cut"——直接治"镜头间不连贯";
2. **矛盾渲染成并集**:提示词人物安排与 pinned 开头帧矛盾时,模型把两者全部渲染(union)——**"多出不相干人脸"的深层根源**,FRAME DISCIPLINE 防不了这种加人;
3. **静止 hold=字面冻结**:"a held framing with nothing happening renders as a literal freeze"——官方证实段尾冻结机理,与第一轮 MOTION DISCIPLINE/QC 截尾同方向。

## 1. Q版发色锁(问题①)

根因:Q 版 img2img denoise 0.93 高重绘下发色只靠 initImage,Z-Image 把双色挑染"平均"成单色;文本锚只有泛指的 "identical hair color",没有具体发色词。

- 新增 `manjuHairPhrases`/`manjuHairAnchor`(manju_pipeline.go):从 image_prompt/appearance/views.q 提取所有 hair/发/fur 相关子句(逗号切分、去重、≤90字),拼 `HAIR LOCK: ... multi-tone must stay multi-tone` 显式锚,前置到 Q 版提示词(人类/兽类双分支);color_palette 第 5 色位(发色)一并点名。
- **存量自愈**:新增独立 `manjuQGen=2` 代数(asset_map.json q_gen 字段),落后则清除全部旧 `*_q.png` 按新逻辑重出(不动 full/side/detail 视图)。

## 2. 段尾冻结自动截尾(问题②③核心)

根因:QC 实测 EP01 冻结比例 0.33~1.0——H3 长镜运动衰减(动作早早 settle 后趋静止)是**模型固有特性**,换 seed 重渲不解决;冻结尾巴直接进成片=每镜结尾停顿=PPT 观感;QC 判不合格触发自愈重渲=无效烧 GPU 循环。

- manju_media.py 新增 `trim_frozen_tail`:每 2 帧采样灰度均值,从尾部找连续冻结游程(相邻差<0.8,容忍 1 个孤立抖动);冻结尾 ≥0.5s 且 ≤40% 总时长时 packet-copy 无损截除(PyAV 18 须用 `add_stream_from_template`)。
- qc 集成:freeze_ratio>0.6 → 自动截尾 → 复检;通过则 `OK·段尾冻结已截尾X.Xs`(不判失败不重渲)。`--no-defreeze` 可关(配置 `render.defreeze=false`)。
- 实测:EP01 04.mp4(10.62s 冻结100%)→ 截除 4.2s → 6.42s 复检通过,音轨完好;截尾后文件合成正常。

## 3. 静音分级(问题③)

- 有台词/旁白镜(plan dialogue 非空或 h3_prompt 含 `<d>`)静音 → `静音丢台词` 仍判失败,并在 stageQC 日志提示可开 `render.voiceover` 走 edge-tts 补配音(只补静音镜,无双声风险)。
- 纯空镜静音 → 软告警(`soft_flags`,ok 不受影响,不触发重渲;换 seed 重渲未必出环境音,BGM 可兜底)。
- stageQC 新传 `--plan`(判定台词)。

## 4. 运动纪律注入(问题②)

- 新增 `manjuMotionGuard` 常量,finalizeShotPrompt 对所有镜头尾部注入:持续运动(镜头运动/人物动作/环境动态三选一)直到最后一帧,禁止提前 settle 成静帧。配合冻结截尾双管齐下:提示词尽量让运动持续,残余冻结程序裁掉。
- **提示词指纹对称修复(顺带发现的隐藏 bug)**:FRAME/MOTION guard 只在 renderShotTo 值拷贝内注入,manifestMark 记"含 guard"指纹而下次 stale 检查用原始 prompt 算指纹——有角色镜恒 stale 反复重渲。修复:抽 `manjuFinalizePromptPure` 纯函数,指纹计算(mark 与 stale 检查)与渲染三处统一。
- 注意:运动纪律改变指纹,**已有镜头会判 stale 全量重渲**(预期行为,motion guard 生效的必要代价)。

## 5. 成片连贯性(问题②)

- **转场默认 cut→dissolve**(stageAssemble;seam 接缝镜仍自动硬切防重影;`render.transition` 显式配置优先)。前端 manju.js 同步默认值四处+参数卡显示逻辑,?v bump 202608271100。
- **按分镜表时长截断**(manju_media.py assemble):H3 帧数按 17k+5 网格量化,产物常比计划多 ≤0.7s 运动衰减尾巴;合成时每镜截到 plan duration×fps(只截短不补长,多切点长镜组头=组内求和),成片节奏回归分镜设计。实测截尾后文件合成正常。
