# NiliX 升级记录 2026-08-26

本次升级（全部落地并编译通过、冒烟测试 OK）共 5 项：

## 1. 官方 Context IR 提示词扩写（空镜）

- 接入 MiniMax 官方 `POST /v2/h3_context_ir`（复用 2K 的 MiniMax API Key），对**空镜**（FL2VA 三段式）提示词做官方增强，输出格式与空镜一致直接替换。
- 角色镜（Ref2VA 六段式含 `<Picture N>` 引用）暂不扩写（IR 文本模式输出无参考图引用，避免丢主体映射）。
- 配置 `render.ir_expand`（默认开；未配 MiniMax Key 自动跳过；失败降级用本地提示词不阻塞）。
- 手动触发：`POST /api/manju/ir_expand`（body: `{config, episode}`），改完提示词后可重跑。
- 新文件 `internal/api/manju_ir.go`；管线内集成于 `genShotPrompts` 写盘前。

## 2. SageAttention 缺省开启 + video VAE 换 int8

- 新增 `sageEnabled()` helper：`render.sage_attention` 缺省按 **true** 处理（存量项目 config 无该字段也生效）；节点缺失时 `sageAttnGuard` 仍自动降级关闭不阻塞。
- video VAE 默认 `minimax_h3_video_vae_int8_convrot.safetensors`（省显存，NiliX 本地已有该文件）。
- 改动点：`internal/config/config.go`、`internal/api/manju_pipeline.go`（sageEnabled + 项目默认）、`manju_comfy.go`、`manju_agent.go`、`manju_agent_health.go`。

## 3. 台词/旁白 srt 自动导出

- `assemble` 新增 `--srt` 参数：把每镜对白（`<d>`）/旁白（narration）字幕窗口导出为 srt 文件（成片同目录 `<成片名>.srt`），**默认导出、不烧录**（H3 原生音轨 + 画面无字幕保持）。
- 配置 `render.srt_out`（默认 true，false 关闭）。
- 改动点：`internal/api/scripts/manju_media.py`（`_write_srt`/`_srt_ts`）、`manju_pipeline.go` stageAssemble 传参。

## 4. 渲染空闲自动释放显存

- 管线渲染完成后空闲 N 分钟（`render.idle_free_minutes`，默认 10，0=关），且 ComfyUI 队列无任务时自动 `POST /free` 释放模型显存。
- 改动点：`manju_comfy.go`（`queueBusy`）、`manju_pipeline.go`（`scheduleIdleFree`，管线收尾调用）。

## 5. QC 视觉抽检

- QC（音轨/亮度/冻结/OCR）通过后，对每镜抽 1 帧，本地视觉模型判断画面崩坏/花屏/畸形/五官错乱，命中写回 QC 报告（触发自动重渲，与现有 QC 行为一致）。
- 配置 `render.qc_vision`（默认 true）；未配视觉模型（`agent.vision_model` / `GLM_VISION_API_KEY`）自动跳过。
- 改动点：新文件 `internal/api/manju_qcvision.go`、`manju_pipeline.go` stageQC 接入。
