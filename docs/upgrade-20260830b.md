# H3 漫剧五问综合整改(2026-08-30b,script_parse_ver 14→15)

用户实测反馈五项:①内心活动配音重复 ②角色配音分不清人物、乱对角色嘴型
③角色站位分镜描述不够清楚 ④运镜垃圾 ⑤人物渲染动作僵硬不协调自然。
本整改四层并举(机械修复 → LLM 规则 → QC 拦截 → 存量同步),全部改动经
单测/全量存量实证/编码体检/交付检查验证。**提示词改词=缓存失效,存量镜头
重渲后新效果生效(脚本直出项目由 script_parse_ver=15 自动重解析)。**

## 一、内心配音重复(问题①)

**根因(EP01_direct_plan.json 镜4/5/6/14 实锤)**:`scriptValidateShots` 机械补写
(manju_script_parse.go)对 narration 只剥「旁白」前缀不剥「内心·」→ 补写 key 带
「内心·阿影:」前缀恒匹配不上 h3_prompt(LLM 已剥离前缀的正确写法)→ 每次导入
都补出一条带字面量标签+引号的重复画外音 `<d>` 句,成片同一句念两遍且把
「内心·阿影:」标签逐字念出。全量存量基线:472 分镜脚本 9720 镜中 **797 镜**
命中旧逻辑重复补写。

**修法**:
- 补写前 `stripNarrationPrefix` 剥「内心·角色名:」「旁白:」「(Sx)」前缀、循环剥
  引号与标点、中间成对引号转句号、内容补规范句号;
- 补写判定改**逐句命中**(行内多句任一子句在 h3_prompt 中命中即不补);
- LLM 规则 3/4 增补:禁止 d 标签内带「内心·/旁白:」前缀与中文引号、同一句
  台词/旁白/内心在整条提示词中只能出现一次;
- QC 拦截:cmd_asr 新增**多念检测**(期望句在实听中出现多次→失败)与**标签检测**
  (「内心·」「旁白:」被逐字念出→失败)——旧判定只查「该念的念了」不查「多念的」,
  重复问题复发即自动拦截返工;
- manju_voiceover 双声根治:该镜 h3_prompt 已含内心句 off-screen `<d>`(H3 原生
  已念)直接跳过 TTS,不再依赖 RMS 阈值(音量低即双轨的历史坑)。

**实证**:模拟新旧逻辑对全量存量脚本:旧逻辑 797 镜重复补写 → 新逻辑 28 镜
(真缺失补写/近似误差,Go 单测覆盖核心形态 0 补写)。

## 二、配音分不清人物、乱对角色嘴型(问题②)

**根因(EP01 实锤)**:
1. 内心戏画外音**挂载侧音色错配**:注入侧绑定 beast_cute 兽音,挂载侧
   `manjuOffscreenKey` 按关键词猜音色,「a cute, playful creature voice」无性别
   年龄词 → 默认 male_mag 中年男声,四镜内心戏全挂错(描述与参考音频自相矛盾);
2. `ensureVoiceBindings` 只要已有任意 1 条 `<Audio `(内心戏定义)就整体 bail →
   同镜说台词的登场角色无音色挂载,与画外共用默认声;
3. 画外说话人用普通 `(S1) says:` 句式(无 off-screen voiceover 标记)→ H3 把台词
   安给画面角色动嘴(镜5/11 程野不在场仍普通 says 实锤);
4. `manjuAudioDefTarget` 与 `reAudioDefLine` 捕获组口径不一致(官方对齐形态
   `<Subject N> (Sx)` 无 for 前缀解析恒空,挂载靠回退碰巧对上,画外定义截断错位);
5. 括号说话人(「挑战者程野(剪影)」)匹配不上 → 不进 Sx 注册表。

**修法**:
- `offscreenVoiceKeyFor` 单一事实源:「the quiet inner voice of X」→ 归一匹配登场
  角色 → `autoVoiceFor` 角色音色;「narrator…」→ male_narrator;其余才关键词猜测;
- `ensureVoiceBindings` 逐角色补写(只补缺定义的角色,编号 maxN+1 接续,幂等);
- `markOffscreenSays` 机械 off-screen 标注:裸 `(Sx) says:`(含逗号变体)→ 改写为
  `says in an off-screen voiceover`,并在句末 `</d>` 后补 lips-closed 从句
  (画面角色 `<Subject N> (Sx) says` 形态不动;幂等);
- `manjuAudioDefTarget` 兼容无 for 前缀形态(对齐/挂载两侧解析统一);
- `charIDMatch` 剥括号标注 + `buildSpeakerRegistry` 注册「内心·」角色。

## 三、角色站位描述不清(问题③)

**根因**:存量脚本六段式站位稀疏(EP01 14 镜 8 镜 detailed_description 零位置词),
「脚本即权威」逐字保留无人补;LLM 重写词预算(150-220 词)挤掉站位;无站位校验。

**修法**(机械层,不动脚本文本):
- `injectPositionDiscipline` 渲染前注入 POSITION DISCIPLINE(幂等锚):每个登场角色
  必须有屏幕位置(左/中/右三分位+前/中/背景)+朝向(facing camera/left/right/
  turned away),镜内相对位置不得翻转——新渲染即生效;
- `scriptValidateShots` 新增站位 WARN:画面描述零位置词 → 解析日志告警提示补写;
- 新脚本由创作侧模板【位置锚定纪律】与 LLM 规则 36 已立(ver14)。

**基线**:全量存量 9720 镜中 **5649 镜(58%)** 无任何位置/朝向词 → POSITION
DISCIPLINE 覆盖。

## 四、运镜垃圾(问题④)

**根因**:运镜=分镜运镜列照抄,无景别↔运镜匹配校验,无机械兜底(LLM 软规则可
忽略);「固定」机位镜(存量 5116 镜,53%)与画面动作衰减叠加=成片趋静;截断重试
精简模式可能丢运镜。

**修法**:
- `manjuCameraPhrase` 运镜三要素机械提取:括号英文直取(Push In, small, slow)/
  「固定」→ static locked-off/中文映射表兜底(缓推/急推/横移/跟移/慢升/缓拉/
  缓摇/甩镜/过肩/低机位/贴地/俯拍/仰拍/升降/环绕);
- `injectCameraDiscipline` 渲染前注入 CAMERA DISCIPLINE(幂等锚):本镜运镜必达,
  固定镜显式声明 static + 画面动作/环境动效撑帧(与 MOTION DISCIPLINE 三选一
  不冲突);
- LLM 规则 7 增补景别↔运镜匹配表(特写近景→推/摇/固定小幅;中景→推拉横移跟移;
  全景→横移跟移升降;远景→升降缓推航拍;对话对峙→固定+微摇禁纯静止);
- `scriptValidateShots` 新增运镜 WARN(运镜列为空/长固定镜≥6s)。

## 五、人物渲染动作僵硬(问题⑤)

**根因**:QC 实测 freeze_ratio=1.0 段尾冻结(模型固有运动衰减+pin头0.92s+气闸
1-2s 叠加);规则 24「单一主导动作+小幅+慢速」刻意弱化幅度,与 EXECUTION
DISCIPLINE「clearly perceivable amplitude」互相矛盾;判停清单禁写走位,位移类
动作先天缺失;动作-对白协调无校验。

**修法**:
- LLM 规则 24 修订:动作幅度分级——爆发镜大幅快速(带惯性起步-发力-收势)/
  常态镜中幅自然/情绪镜微表情三层拆解;一步以内小位移(转身/跨步/俯身)直接写,
  跨屏位移才写「已到位」;
- LLM 规则 18 增补收尾动作:每镜结尾必须落明确完成态动作(落座/转身/收拳/抬头),
  禁止静止定格收尾;
- `scriptValidateShots` 新增动作-对白协调 WARN:有台词镜画面描述无动作/表情词
  → 告警(存量 329 镜命中);
- 气闸/接缝保持既有 CHAIN DISCIPLINE(微动作撑帧已含)。

## 六、拆镜密度放宽(用户新规则)

「为了画面精细完美,分镜头可以多,保证小说内容能完整表达出来」:
`manjuDurationRule` 拆镜密度由「每 100-160 字一镜」放宽为「每 80-130 字一镜」,
新增「内容表达完整优先,宁多镜不压缩,拆镜数不设上限;一个节拍放不下就拆两镜,
长对白拆多句、多动作拆多镜」。角色 ≤3/对白 ≤20 字等硬约束保留。
