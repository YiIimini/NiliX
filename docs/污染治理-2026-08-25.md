## 一、污染根因（按严重度排序）

### 1. config.style 非美术风格词混入提示词（主因）
`manju/铁心机兵/config.json` 的 style 是：
`real+玄幻修仙+电影级运镜+电影动漫写实风格+场景唯美+反派磕碜+Q版呆萌可爱小角色(用于对应角色的动态内心独白)+二次元动漫写实风+真情实意+正能量+正角帅气或美丽+配角谄媚`
- 旧代码 `manjuStyleDesc` 对"+"分隔的自定义段**原样保留**（中文不翻译、括号不剥离）
- 这些词被拼进**每个角色 image_prompt / 场景 image_prompt / 每镜 H3 提示词 / BGM 定向**
- 实测后果：阿铁定妆照全息屏被画成汉字"呆"（Q版呆萌指令诱导）；BGM 定向成古筝（古风词→guzheng）；
  赛博朋克废土剧被"玄幻修仙"拉向修仙古风
- 来源：GUI 风格输入框把"角色塑造规则/内容价值观/跨书残留题材词"当成风格词填入

### 真实渲染验证发现的第 6 类污染源（comfy_output 路径错配，2026-08-25 下午实测）
- **现象**：修复后重跑 plan→assets→render，产出的资产/视频 MD5 与旧污染版完全一致（阿铁/深渊坑/01.mp4/02.mp4 字节相同）。
- **根因**：`settings.json` 的 `paths.comfy_output` 指向废弃路径 `NiliX\ComfyUI\output`（早期内置 ComfyUI 残留），而 ComfyUI 实际输出在 `ComfyUI-Shared\output`。`main.go` 的 `SetComfyParams` 用 settings.json 注入 → 覆盖项目 config 的正确路径 → `comfyGenImage`/`renderShotTo` 从错误目录拷到**旧污染产物**（NiliX\ComfyUI\output 里残留 11:31 旧任务文件）。污染治理后的重跑实际复用旧文件——这是"修了还不对"的隐性根源。
- **修复**：`settings.json` `comfy_output` → `C:\Users\Administrator\AppData\Local\Comfy-Desktop\ComfyUI-Shared\output`；`NiliX\ComfyUI\output` 旧文件归档到 `ComfyUI\output\_archived_2026-08-25`；清空 assets/clips 后重跑。
- **验证（真实链路）**：阿铁.png MD5 `2DC99FF9`(旧) → `123F5185`(新)；01.mp4 `526F242A`(旧) → `3B628FBC`(新)、02.mp4 `5FCE2C76`(旧) → `58ED6863`(新)；OCR 无异常文字。17 镜、场景全关联、image_prompt 零中文污染。
- **遗留排查经验**：NiliX 配置优先级 `comfyParams()`（settings.json 注入）> 项目 config.json > 兜底 Shared。怀疑产物"没变化/没生效"时，先对 `settings.json` 与项目 `config.json` 的 `comfy_input/comfy_output`。
