# ai-film-skills 深度解析与 NiliX 渲染管线整合

> 分析对象：[L-Trunks/ai-film-skills](https://github.com/L-Trunks/ai-film-skills)（2026-08 克隆，86 文件）
> 整合目标：NiliX 漫剧渲染管线（`internal/api/manju_*` + `manju_media.py`）
> 文档结论：本仓库的核心价值是**一手踩坑经验 + 反同质化机制 + 无人值守验收方法论**；其中部分知识在 NiliX 既有提示词纪律中已落地（规则 14-18），本次补齐剩余高价值缺口。

## 一、仓库概览

该仓库是「本地 AI 短片的导演经验库」：**六个 Claude Skill，管的是『这一部片该怎么想』**，不依赖任何脚本/模型，纯 Markdown 方法论。作者用 RTX 4070 Ti 12G 实跑三部成片（《狱卒》带对白剧情片 / 《九尾》58 段链式长片 / 《山海》short-shot 预告片）。

### 1.1 结构

| 部件 | 管什么 |
|---|---|
| **local-ai-film**（中枢 ★） | 开片仪式（profile → 变量表 → 指纹 → 骨架 → 镜头数 → 分镜 → 探针 → 跑批 → 后期 → 验收 → 写回指纹） |
| `profiles/` | 模型能力参数（`max_shot_sec`/`motion_style`/`text_sensitivity`…），正文不写常数 |
| `directing/` | 反同质化：正交变量表 + 双层指纹 + 骨架库（含 use_count） |
| `knowledge/` | 踩坑库：pitfalls / prompt-craft / shot-list-prompt / chain-consistency / dialogue-drama / auto-review / post-production / bgm-spectral |
| 五个卫星 | emotion-to-camera-language（情绪→镜头语言四件套）、lock-character-reference（形象先锁定）、shot-breakdown（批量筛图判停）、rhythm-density（疏密节奏）、material-driven-storyboard（素材反推分镜） |

### 1.2 可信度体系（最值得学习的元设计）

- 每条数值带 `verified` 字段：**`本机实测` 与 `转述` 严格分开**——仓库里只有 `ltx-2.3-q4-12g` 一份是本机实测，Wan/可灵/即梦参数「没跑过就不写，写了就是抄文档害人」。
- 经验按 profile 分族（short-shot 2.04s vs long-shot 5-15s），**两族知识互相矛盾**（动作弧线/文字载体/关系性动作结论相反），读知识前先确认自己在哪一族。
- 卫星 skill 用 RIA 蒸馏格式 + 审计信息（验证通过/盲点/容易混淆的邻近方法论）。

## 二、知识点深度解析（按价值排序）

### 2.1 ★ 反同质化：正交变量表 + 双层指纹（`directing/variables.md` + `fingerprint.md`）

**问题**：「记得每次不一样」被证明无效——作者四部预告片逐镜同构（第 25 镜全是「摘面罩+近乎全黑」，第 36 镜全是「大远景空景收尾」），四部氛围片全是 17 镜。

**机制**（三件套）：

1. **正交变量表五维**：时间结构（线性/倒叙/循环/平行切/单时刻切片）× 视点（全知/跟随单人/监控·仪器/物的视角/缺席）× 节奏型（匀速/加速爆发/前紧后松/两次呼吸/全片凝滞）× 声音（BGM通铺/对白驱动/音效驱动/环境声/完全静音/声画错位）× 结尾（空景收/回到首镜/硬切黑/悬而未决/日常化）。每维带状态标记（✅已验证/🟡部分/⬜未自测/🔴用太多应避开/⚠️有前置条件）。
2. **双层指纹查重**（`films.jsonl` 每行一部片）：

| 层 | 规则 | 范围 | 动作 |
|---|---|---|---|
| `vars` | 撞 ≥3 维 | 最近 3 部 | 重选，硬拦 |
| `structure` | 相同 | 最近 3 部 | 须给显式理由 |
| `signature` | 撞 ≥2 项 | **全部历史** | 重设计 |

   `signature` 五字段：`shot_count / opening_size / ending_size / peak_device / climax_pattern`——**写手法不写题材**（写「摘面具」而不是「防化服人员摘面具」）。文本字段语义等价即算撞；数值字段 ±10% 内算撞。
3. **闭环写回**：成片验收后追加一行到 films.jsonl，**漏了整套机制静默失效**。

**可信度**：`本机实测`（8 部历史片录入，三条已知重复：ending_size 大远景 7/8、shot_count 17 4/4、trailer-8seg 4/4）。

**分集例外**：同一系列第 02 集**就该**和第 01 集同 structure——`structure` 层按系列查，`vars`/`signature` 照常逐集查。

### 2.2 ★ 踩坑知识库（`knowledge/pitfalls.md`，16 坑，全部本机实测）

与 NiliX 管线直接相关的精华：

| 坑 | 内容 | 与 NiliX 关系 |
|---|---|---|
| ⑪ concat 后必须重建时间戳 | 不 `setpts=N/FPS/TB` 静默丢帧（6062→6013 帧无报错），且累积漂移 | **NiliX 已具备**（assemble 逐帧 `frame.pts = vpts; vpts += 1`）✅ |
| ⑫ 提示词文字会被画进画面 | 数字风险最高（「二十五六岁」被画成字幕）；比喻类喻体被画成实物（「烫疤像大硬币」→ 手腕真出现硬币）；「画面无文字」句无效 | **NiliX 规则 17 已整合**（零数字+类比禁令）✅ |
| ⑮ 通用超分拧坏小人脸 | 人脸短边 <110px 时 ESRGAN 破坏性（五官熔团/十字伪纹理），>150px 无害；修法在生成阶段：提分辨率/改景别/换种子，按段分治只是兜底；CodeFormer 对奇幻角色是负资产（把琥珀金瞳改灰蓝，fidelity=0.9 拦不住） | NiliX 走云端 2K 再生（非 ESRGAN），但「脸小要改景别」对 plan 景别选择有参考价值 🟡 |
| ⑧ 负向提示词在 I2V 阶段可能不存在 | 工作流 negative 接 ConditioningZeroOut → 负向全白写；「让它动起来」会召唤隐含施动者 | NiliX H3 为 CFG-distilled 无负面词（已按正面排除句转译），同源认知 ✅ |
| ⑥ 一致性阈值不能照搬真人经验 | AI 生成同角色余弦相似度天然低（0.338-0.417 vs 真人 0.5+），阈值 0.28；色彩统计无区分度，必须语义嵌入 | NiliX 用 Ref2VA 参考图+VLM 判分，未用嵌入相似度；未来若加嵌入校验须本机标定 🟡 |
| ① 显存泄漏必须每镜重启 | 权重大于显存时 offload 不释放，只有进程退出能还内存 | NiliX 本地 ComfyUI 常驻+渲染前 ensureComfyReady，显存策略不同 🟡 |
| ⑩ 验收必须抽帧 | 拼片成功≠能看；查乱码文字/人物一致/辉光/末帧漂移/指纹写回 | NiliX 机械质检+审片抽帧已有 ✅ |
| ⑬ Windows 三个静默失败 | 文本模式写文件 CRLF / cv2 中文路径静默失败 / 片源尺寸不能写死（应 ffprobe 实测） | NiliX Go 侧 utf-8 写文件 + ffprobe 探测已有 ✅ |

### 2.3 ★ 带对白剧情片（`knowledge/dialogue-drama.md`，long-shot 族）

- **常量层**：角色/场景描述收进共享模块，分镜只引用不复制；`never` 一个都不许写（在 cfg=1 工作流里不是不生效是**召唤 X**）；三个画风锚 LOOK/LOOK_OBJ/LOOK_BACK（物件镜/背影镜去掉人脸布光段）。
- **判停清单**（模型做不到的六类，换写法不要重抽）：

| 做不到 | 换成 |
|---|---|
| 机械开合（舱盖/抽屉） | 关着空镜硬切开着空镜 |
| 群体连锁反应（依次回头） | 单人反应+画外声 |
| 走位（走进来/走出画） | 直接画「已到位」（位移做不出，**原地姿态变化可以**） |
| 画内文字 | 只留大号阿拉伯数字 |
| 多人互动（A 给 B 戴） | 拆单人镜，视线缝起来 |
| 手部纹理级特征 | 姿势级特征 |

- **★ 状态变化镜画「之前」**（实测 4 例全倒放）：关键帧=首帧，视频模型只能从它往后演；写「涟漪扩散/裂缝亮起/红指印留下」的**终点**，模型就倒着演回起点。规矩：**状态会变的镜，关键帧画「之前」，变化交给 motion**。配套：别用首尾同图锁终点姿势；有关键数字的镜不改首帧（T2I 画大号数字稳、视频模型不稳）。
- **台词只能有一个来源**（提示词/配音/字幕/剪辑表四个下游从同一份取）。
- **BGM 通铺已破**：判据换成「对白交锋段一律不给音乐」（覆盖从 94% 降到 19%/34%）。
- **四个「各算各的」bug**：抢话（全片时间轴顺扫级联）、字幕重叠（信息条分层）、音效漏加工（名单与实现同一份数据）、BGM 通铺。
- **出片顺序**：剪辑 → 超分（混音前）→ 混音 → 字幕（字幕字号按成片分辨率标定）。

### 2.4 提示词工艺（`knowledge/prompt-craft.md` + `shot-list-prompt.md`）

- **去 AI 味**：不堆「电影感/史诗/masterpiece」，换具体摄影参数（35mm 胶片/柯达金 200/手持微晃/浅景深）；**戏剧强度越高越假**，普通瞬间才真；人物镜脱离通用 LOOK 换纪录片语言（「没有任何戏剧打光」这句压掉电影感先验）。
- **概念盲区判据**：重抽第 2 次错误方向与第 1 次一致 = 盲区不是概率问题，**停止加词，换主体**（洞螈→洞穴盲鱼）。
- **缺席表达**：写「某物不在场但留下痕迹」，模型必然把某物画出来——否定句必须**逐项列全**（「椅子上没有人，画面里没有任何人体、四肢或衣物」）。
- **构图指令权重之争**：指令句被几百字描述稀释 → 画面塌回默认构图。两条有效杠杆：**夹句**（核心指令首尾各一遍）+ **画幅裁切**（「上三分之一只有天，下三分之一只有地，他装在中间那条带子里」= 物理上塞不下别的东西）。堆形容词无效；**水平左右位置提示词治不好**（实测三种写法全零效果），有效解法在提示词外：裁画幅（T2I 出图高于视频分辨率，横向有冗余）。
- **长单镜结构化分镜表**：写时间码（切点误差 1.7%）、关系感写成「距离+朝向镜头的物理动作」（「她的头靠在镜头的肩上」→ 必失败）、角色描述每段原样重复、【导演备注】写编号祈使句硬规则。
- **测量纪律**：判提示词改法有没有用必须同种子对照或 4 抽比均值（种子噪声 ±0.05，拿单张比单张会误判）。

### 2.5 链式长片一致性（`knowledge/chain-consistency.md`）

- 尾帧接首帧，**每 3 段强制重锚定**；锚定提示词必须带**完整角色描述**（只写「她所在的场景」= 自由发挥）；**空镜绝对不能锚定**（锚定图必然带角色）；主角属性会渗给同框所有人（配角必须有和主角一样完整的定妆描述，**尤其是发色**）；角色描述零数字；尾帧必须抽真正的最后一帧（`-sseof` 会抽到 N-4）；剪短镜头**砍头保尾**（保尾帧接首帧的链）。

### 2.6 无人值守验收（`knowledge/auto-review.md`）

- **「我判不准」必须变成能算的数**：背对→人脸数==0；人在画左→bbox 中心 x；全景→膝/踝关键点 score；黑图→像素 std<6。判据从分镜自己的字段推，不另写一份。
- **⛔ 检查器上岗前必须跑误杀回归**（拿历史合格素材跑，查「误杀」不是「漏杀」）——没验证过的检查器整夜杀好图，比不装坏得多。
- 存疑不放行（下游重跑代价差一个量级）**但也要重抽**（夜里 GPU 闲着）。
- 跨镜一致性：只在两张都测准且互相矛盾时才判不合格，「测不出来」不算证据；平局不是多数派；过了就冻结（frozen 集合，防邻镜重抽翻案已合格镜）。
- 废稿移走留证不删（带轮次号）；重抽有上限；报告写明机器判不了什么（画风/情绪/构图）。

### 2.7 声音（`knowledge/bgm-spectral.md`）

- **选曲判据是频谱不是节奏感**：质心/滚降/低频占比/调性三档（清新通透 ~2000Hz/~4200/15%/大调；深邃 ~1400/~2960/33%/小调；压抑惊悚 ~550/~440/61%）；「深邃≠发闷，分界在滚降」。
- 成片音量两套标准：有旁白 0.05-0.06 RMS，无对白氛围片 0.075。
- `bgm_vol` 别指望一次调准，出片后统一调平（只重编码音轨，视频流 copy）。
- 曲库定期体检（重复文件/档位失衡→创作多样性被曲库锁死）；**把选曲固化成命令比写说明有效**（作者自己也栽过：凭文件名选曲选了被判「诡异」的那首）。
- 许可纪律：CC-BY 发布必须署名，ND/SA 不能用作 BGM，抓取即记录 LICENSES.jsonl。

### 2.8 卫星 skill 速览

| 卫星 | 核心命题 | 可信度 |
|---|---|---|
| emotion-to-camera-language | 「氛围感」是结果不是指令：拆成**光位/景深/机位/人物状态**四件套，每项一句可执行描述（能照着装机器）；逆光是电影感最大单一来源；堆形容词是负资产 | 转述+部分验证 |
| lock-character-reference | 角色固定形象图必须先跑出来，跑不出就停；本地 Qwen-Image-Edit 只能同底图编辑，换机位换景别即崩→**角色数压到 1-2 个** | 转述+本机实测 |
| shot-breakdown | 矩阵生图后「工作是筛不是抽」；判据是分镜意图不是好看；同镜重抽 3-5 次判停，弃用改故事不硬修 | 转述+本机实测 |
| rhythm-density | 节奏靠疏密对比（高能段快切/首尾呼吸，比例 ≈1:1.7），秒数按 `max_shot_sec` 缩放不照抄绝对值；伪长镜=同机位两镜极缓运镜拼接 | 转述 |
| material-driven-storyboard | 分镜起点是「手上有什么素材」不是「理想画面」；凑不出来的镜头三选一：换素材/静态图+Ken Burns/改故事 | 转述 |

### 设计要点

- **不阻塞生成**：指纹撞维输出为「警告+要求显式差异化」，不硬拦（保续跑兼容）；旧方案（无 directing 字段）正常复用，不强制重生成。
- **分集例外**：同一小说（系列）各集 `structure` 层不查（仓库明文规则），`vars` 查近 3 集、`signature` 查同小说全历史。
- **语义等价判定降级**：仓库用语义等价判定文本撞维；Go 侧先用**精确匹配**（+±10% 数值），语义层留给 LLM 在警告中自行判断，文档注明局限。
- **零新依赖**：OCR 扫描 rapidocr 未装即跳过；BGM 选曲只用 PyAV+numpy（venv 已有）。
